# Acopio Transparente

## Requisitos

- Node.js 20 o superior
- npm (viene con Node.js)
- Extensión [Freighter](https://www.freighter.app/) en el navegador, configurada en Testnet. Solo hace falta para conectar la wallet en los formularios; el tablero público funciona sin ella.

## Instalación

```bash
cd frontend
npm install
```

## Cómo correrlo

```bash
npm run dev
```

Abre http://localhost:3000 en el navegador.
